# Perubahan Harian — 2026-10-29

## Ringkasan

Codebase PRIMA dirapikan dengan memusatkan perilaku yang digunakan bersama,
memindahkan proses infrastruktur dari controller ke service, menyatukan konstanta
frontend, serta menambahkan standar format dan dokumentasi pemeliharaan.

## Latar belakang

Controller dan file frontend memiliki beberapa implementasi berulang. Struktur
tersebut menyulitkan perubahan karena format response, audit, konfigurasi SMTP,
label role, dan status harus diperbarui pada lebih dari satu lokasi.

## Perubahan yang dilakukan

- Menyatukan format response API, pemeriksaan role, pengaturan sistem, dan audit
  dalam concern bersama.
- Memindahkan proses pembuatan backup PostgreSQL dan backup portabel ke service.
- Menyatukan validasi serta konfigurasi SMTP untuk reset password dan scheduler.
- Memusatkan label role dan status checklist frontend.
- Membuat komponen loading dan error yang dapat digunakan lintas halaman.
- Memecah `frontend/src/App.jsx` berdasarkan tanggung jawab menjadi fitur
  autentikasi, layout terautentikasi, halaman dashboard, dan reusable hook.
- Mengurangi `App.jsx` dari 1.517 menjadi sekitar 57 baris sebelum formatting
  tanpa mengubah route dan kontrak API.
- Menghapus komponen daftar checklist lama yang tidak lagi direferensikan karena
  route aktif telah menggunakan `ChecklistDataPage`.
- Menambahkan EditorConfig, konfigurasi Prettier, dan pedoman arsitektur.
- Membuat folder dokumentasi testing dan perubahan harian beserta template.
- Merapikan format model pengguna menggunakan Laravel Pint.
- Menambahkan suite Unit Testing terpisah pada konfigurasi PHPUnit.
- Memindahkan aturan status masa berlaku E-KIM ke kelas domain murni agar dapat
  diuji tanpa HTTP dan database.
- Menambahkan 11 unit test untuk status E-KIM dan kesiapan konfigurasi SMTP.
- Memperluas Unit Testing menjadi 41 test untuk tujuh unit domain/service.
- Mengekstrak aturan masa berlaku checklist, alasan penolakan, evaluasi
  verifikasi E-KIM, normalisasi kendaraan, dan pembentukan pesan notifikasi dari
  controller/command ke kelas domain terpisah.
- Memperluas Unit Testing kembali menjadi 76 test untuk sebelas unit.
- Mengekstrak kebijakan workflow, kebijakan tanda tangan, canonical hash/HMAC,
  serta batas retensi audit dan backup.
- Melakukan audit Unit Testing terhadap 34 file aplikasi backend dan
  infrastruktur pengujian frontend.
- Mengekstrak kebijakan batas sesi, ketersediaan sistem, validasi nama backup,
  dan verifikasi checksum dari middleware/command ke kelas domain terisolasi.
- Menambahkan pengujian untuk Turnstile, security header, generator XLSX,
  kontrak API concern, konfigurasi model, dan tiga policy system.
- Memperluas Unit Testing menjadi 119 test dengan 183 assertion.
- Mencatat belum tersedianya test runner frontend dan coverage driver PHP
  sebagai gap audit, bukan sebagai hasil lulus.
- Menambahkan runner Unit Testing frontend tanpa dependency baru dan lima test
  untuk konfigurasi label role, role operasional, serta status checklist.
- Memulai tahap Integration Testing dengan mengaudit 37 test yang sudah ada.
- Menambahkan tujuh Integration Test untuk lockout login, akun nonaktif,
  maintenance, logout token, token reset kedaluwarsa, approval registrasi, dan
  lifecycle dokumen private.
- Memperluas Integration/Feature Testing menjadi 44 test dengan 266 assertion.
- Mencatat dua kegagalan awal akibat cache guard pada test, perbaikan isolasi
  autentikasi, dan hasil pengujian ulang yang lulus.
- Mengaudit 61 route API secara lebih rinci dan memperluas Integration Testing
  menjadi 59 test dengan 370 assertion.
- Menambahkan Integration Test administrasi, lifecycle checklist, kendaraan,
  dan lifecycle SPV Regional Manager.
- Menemukan defect HTTP 500 pada endpoint update checklist akibat dependency
  controller tidak diteruskan oleh closure route.
- Mengarahkan route PUT checklist langsung ke controller dan meneruskan route ID
  melalui parameter action agar dependency injection Laravel kembali bekerja.
- Mencatat empat route yang masih membutuhkan Integration/System Test khusus,
  terutama metadata PostgreSQL dan backup database.
- Menyelesaikan audit Integration Testing pada seluruh 61 route API.
- Menambahkan empat test untuk daftar dokumen, pembacaan settings, endpoint
  retensi, dan kontrak endpoint backup.
- Membuat metrik tabel settings portabel untuk PostgreSQL dan SQLite tanpa
  mengubah kontrak response API.
- Menutup tahap Integration Testing dengan 63 test dan 398 assertion; regression
  keseluruhan mencapai 182 test dan 581 assertion.
- Memperdalam audit dengan 36 kombinasi role-endpoint dan pengujian request
  tanpa token pada kelompok route terproteksi.
- Menemukan defect keamanan mutasi checklist lintas Integrated Terminal pada
  create, update, delete, workflow, dan digital signature.
- Menambahkan pemeriksaan terminal sebelum setiap mutasi checklist dan
  memastikan request lintas terminal menghasilkan HTTP 403.
- Memperbaiki tiga fixture lama yang tidak mengisi `terminal_id` agar sesuai
  dengan struktur operasional multi-terminal.
- Memperluas Integration Testing menjadi 103 test dengan 450 assertion;
  regression keseluruhan menjadi 222 test dengan 633 assertion.
- Memulai System Testing dengan audit runtime, migration, scheduler, HTTP,
  security header, frontend build, Docker Compose, dan CI/CD.
- Menemukan validasi overlay produksi gagal karena variabel Regional Manager
  belum disediakan pada job CI Compose.
- Menambahkan env Regional Manager pada validasi CI dan menjalankan ulang
  production Compose config hingga lulus.
- Menambahkan Unit Testing frontend ke pipeline sebelum production build.
- Menjalankan HTTP smoke test dengan database sementara yang dimigrasikan dan
  mencatat Docker runtime sebagai belum diuji karena akses daemon ditolak.
- Menyusun instrumen Acceptance Testing/UAT yang siap digunakan di kantor untuk
  enam role aplikasi beserta skenario tugas, pertanyaan penerimaan, pertanyaan
  umum, temuan defect, kriteria penerimaan, keputusan, dan tanda tangan.
- Menambahkan Google Apps Script yang otomatis membuat Google Form UAT dengan
  percabangan enam role dan spreadsheet respons di Google Drive.
