# Perubahan Harian 2 November 2026

## Ringkasan

Role legacy `user` dikonsolidasikan menjadi `hsse` agar aktor aplikasi konsisten dengan FR/NFR dan use case proposal. Pemisahan kewenangan kendaraan ditegaskan: Pengurus mengajukan kendaraan, SPV HSSE memutuskan serta mengelola kendaraan, dan Tim HSSE melakukan pemeriksaan checklist.

## Perubahan utama

### Role dan otorisasi

- Menghapus `user` dari daftar role backend, role internal, label frontend, pilihan manajemen akun, menu, route guard, dashboard, dan matriks otorisasi.
- Membatasi pembuatan serta pengajuan checklist kepada SPV HSSE dan Tim HSSE.
- Mempertahankan akses baca checklist bagi Integrated Terminal Manager dan Regional Manager sesuai scope masing-masing.
- Mengubah label menu `Kelola Akun User` menjadi `Kelola Pengguna`.
- Mengubah default akun internal baru menjadi `hsse` dan default pendaftaran publik menjadi `pengurus`.

### Alur kendaraan

- Menghapus route API legacy `GET/POST /api/v1/user-vehicles` dan method controller terkait.
- Menghapus menu serta route frontend `/vehicle-registration` milik role legacy.
- Halaman kendaraan yang sah tetap menggunakan alur Pengurus melalui `Kendaraan Saya`; keputusan kendaraan dilakukan SPV HSSE melalui `Kelola Kendaraan`.
- Menghapus komponen frontend registrasi kendaraan legacy sehingga tidak menyisakan kode mati atau masuk bundle aplikasi.

### Migrasi data

- Menambahkan migrasi `2026_11_02_000000_consolidate_user_role_into_hsse.php`.
- Seluruh akun lama dengan `users.role = user` diperbarui menjadi `hsse`, tanpa menghapus akun atau data bisnisnya.
- Pendaftaran lama dengan `requested_role = user` diperbarui menjadi `hsse`.
- Default database untuk role akun menjadi `hsse`, sedangkan default pendaftaran eksternal menjadi `pengurus`.
- Rollback tidak mengubah data `hsse` kembali menjadi `user` karena asal kedua kelompok tidak dapat dibedakan secara aman setelah konsolidasi.

## Kesesuaian kebutuhan

- FR aktor Tim HSSE: pemeriksaan dan pengelolaan checklist tidak lagi terpecah antara `user` dan `hsse`.
- FR-017 sampai FR-020: pengajuan kendaraan berada pada Pengurus dan keputusan berada pada SPV HSSE.
- NFR otorisasi: daftar role backend, frontend, database, dan pengujian menggunakan sumber perilaku yang konsisten.
- NFR maintainability: endpoint serta handler backend legacy dihapus, guard dan test matrix disederhanakan.

## File utama terdampak

- Backend: `PrimaController.php`, `AdminController.php`, `ChecklistWorkflowPolicy.php`, `routes/api.php`, factory, migrasi awal, migrasi konsolidasi, serta test unit/feature/integration.
- Frontend: `domain.js`, `AppShell.jsx`, `DashboardPage.jsx`, `api.js`, `Modules.jsx`, dan unit test domain.
- Dokumentasi: catatan perubahan harian dan laporan testing tanggal 2 November 2026.

## Dampak deployment

Jalankan migrasi sebelum aplikasi baru digunakan:

```powershell
cd backend
C:\xampp\php\php.exe artisan migrate
```

Tidak diperlukan pembersihan database. Migrasi mempertahankan akun dan relasi data lama, hanya mengganti nilai role legacy.
