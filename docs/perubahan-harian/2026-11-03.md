# Perubahan Harian 3 November 2026

## Ringkasan

Codebase diaudit dan disiapkan untuk deployment produksi. Pekerjaan mencakup penutupan kerentanan dependency, penghapusan scaffold serta kode mati, pembersihan artefak lokal, perbaikan lingkungan test, dan optimasi Docker build context.

## Temuan dan perubahan

### Keamanan dependency

- Audit awal Composer menemukan empat advisory pada `league/commonmark`, `symfony/http-foundation`, dan `symfony/mime`; dua di antaranya berstatus tinggi.
- `league/commonmark` diperbarui dari 2.10.1 ke 2.10.7.
- `symfony/http-foundation` dan `symfony/mime` diperbarui dari 7.4.18 ke 7.4.22 beserta dependency terkait yang kompatibel.
- Audit awal npm menemukan dua kelompok advisory tingkat tinggi pada `source-map-js` dan Vite 8.2.2.
- Vite diperbarui ke 8.3.5. Seluruh versi dependency frontend dikunci secara eksplisit agar proses deployment dapat direproduksi.
- Audit ulang Composer dan npm menghasilkan nol advisory.

### Pembersihan codebase

- Menghapus scaffold frontend bawaan Laravel yang tidak digunakan karena frontend produksi berada di folder `frontend`: `backend/package.json`, `backend/vite.config.js`, CSS/JS scaffold, dan `welcome.blade.php`.
- Mengosongkan route web root yang hanya merender halaman Laravel bawaan; seluruh endpoint aplikasi tetap berada pada `routes/api.php` dan health check `/up` tetap tersedia.
- Merapikan script Composer agar tidak lagi menjalankan npm dari folder backend atau membuat SQLite kosong.
- Menghapus fungsi dashboard `UserStatistics` serta CSS registrasi kendaraan lama yang tidak lagi direferensikan setelah role legacy `user` dikonsolidasikan ke Tim HSSE.
- Memperbaiki empat karakter mojibake pada status login/CAPTCHA dan nilai email kosong di dashboard.
- Menghapus artefak yang dapat dibangun ulang: `frontend/dist`, log Laravel, cache PHPUnit, compiled view, file ekspor XLSX sementara, data test storage, cache unduhan audit, dan `database.sqlite` kosong.
- Data bisnis, migration, seeder, test, template checklist SPBU/Industri, dan dokumentasi tidak dihapus.

### Kesiapan deployment

- Menambahkan `frontend/.dockerignore` agar `node_modules`, `dist`, test, dan file environment lokal tidak masuk Docker build context.
- Memperluas `backend/.dockerignore` untuk mengecualikan test, cache, SQLite lokal, compiled view, dan runtime storage.
- Menambahkan `.env.testing` tanpa kredensial produksi agar test konsisten dan tidak menghasilkan warning ketika `.env` lokal tidak tersedia.
- Memformat ulang source frontend dengan Prettier.
- Kedua image Docker produksi berhasil dibangun dari kondisi codebase akhir.

## Tindak lanjut deployment

Sebelum menyalakan layanan di server, isi seluruh nilai wajib pada `.env.production` berdasarkan `.env.production.example`, arahkan DNS domain ke VPS, lalu jalankan deployment sesuai README. UAT kantor tetap merupakan acceptance testing terakhir dan terpisah dari verifikasi teknis ini.

## Publikasi repository deployment

- Menginisialisasi repository Git pada codebase yang sebelumnya tidak membawa metadata `.git`.
- Menetapkan branch utama `main` dan repository tujuan `https://github.com/vaniaesthersaleletang15/TugasAkhir`.
- Memastikan file environment, kredensial, private upload, database lokal, log, dependency, key, serta dump database tidak masuk ke commit melalui aturan `.gitignore`.
- Mengecualikan `backend/.env.testing` dari aturan pengabaian karena file tersebut hanya berisi konfigurasi SQLite in-memory tanpa kredensial dan diperlukan agar pengujian repository dapat direproduksi.
- Menjadikan deployment GitHub Actions bersifat opt-in melalui `PROD_DEPLOY_ENABLED=true`; pipeline tetap membangun image, tetapi tidak mencoba VPS sebelum secret dan environment production siap.
- Menambahkan `deploy/bootstrap-hostinger.sh` untuk menghasilkan secret langsung di VPS, membuat `.env` berizin `600`, dan menyimpan kredensial awal hanya pada `/root/prima-initial-credentials.txt`.
- Bootstrap Hostinger memakai registry GitHub baru `ghcr.io/vaniaesthersaleletang15` dan key Turnstile pengujian yang wajib diganti sebelum produksi final.
- Deployment pertama menemukan backend restart karena `php artisan optimize` memerlukan direktori `resources/views` yang sebelumnya terhapus bersama scaffold Blade; direktori standar tersebut dikembalikan melalui `.gitignore` tanpa mengembalikan halaman yang tidak digunakan.
- Menambahkan laporan `dokumentasi-testing/2026-11-03-deployment-hostinger.md` untuk mencatat kegagalan awal, penyebab, perbaikan, dan hasil smoke test deployment.
- Memperbaiki request tanpa token pada endpoint API agar selalu menghasilkan JSON 401 Indonesia meskipun klien tidak mengirim header `Accept: application/json`; sebelumnya Laravel mencoba redirect ke route web `login` dan menghasilkan 500.
- Menambahkan regression test untuk kontrak autentikasi API tanpa header Accept JSON.
- Publikasi repository merupakan persiapan distribusi source ke VPS dan tidak mengubah fungsi aplikasi maupun skema database.
