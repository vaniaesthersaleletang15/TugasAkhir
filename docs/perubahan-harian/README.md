# Dokumentasi Perubahan Harian

Folder ini menyimpan riwayat perubahan proyek berdasarkan tanggal pengerjaan.
Tujuannya adalah menjelaskan apa yang berubah, alasan perubahan, file terdampak,
dan hubungannya dengan kebutuhan sistem atau perbaikan kesalahan.

## Penamaan file

Gunakan format:

```text
YYYY-MM-DD.md
```

Jika satu tanggal membutuhkan beberapa dokumen, gunakan:

```text
YYYY-MM-DD-nama-topik.md
```

## Isi minimum

- tanggal dan ringkasan;
- latar belakang atau alasan perubahan;
- daftar perubahan;
- file yang ditambah, diubah, atau dihapus;
- dampak terhadap pengguna, API, database, atau deployment;
- referensi dokumentasi testing;
- catatan tindak lanjut atau keterbatasan.

Gunakan [`TEMPLATE.md`](TEMPLATE.md) ketika membuat entri baru.
